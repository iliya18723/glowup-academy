GlowUp Academy - Admin UI & 403/404 Fix

این نسخه بر اساس آخرین P5-ADMIN-403-FIXED اصلاح شده است.

رفع‌شده‌ها:
1) فرم‌های POST پنل ادمین: CSRF برای همه فرم‌ها تضمین شد.
2) فرم‌هایی که در نسخه قبلی HTML خراب داشتند (قرار گرفتن CSRF داخل action) اصلاح شدند.
3) مسیرهای دسته‌بندی، پکیج، کوپن، فروش فوری، ویرایش دوره/جلسه/وبلاگ و سایر عملیات POST اصلاح شدند.
4) علامت‌ها و نقل‌قول‌های اضافی که در بعضی فرم‌ها روی صفحه دیده می‌شدند حذف شدند.
5) دکمه‌های عملیات واضح‌تر شدند و کنترل انتقال جلسه متن «↑ بالا / ↓ پایین» دارد.
6) پنل راهنمای کوتاه و استایل دکمه‌ها/فرم‌ها برای خوانایی بهتر اضافه شد.
7) هنگام ارسال فرم، دکمه به «در حال ذخیره…» تغییر می‌کند تا دوبار کلیک باعث ارسال تکراری نشود.
8) Session/CSRF لوکال در server.js همچنان با COOKIE_SECURE=false و TRUST_PROXY=0 قابل اجراست.

اجرای لوکال:
- npm install
- npm start
- http://localhost:3000

اگر .env داری، برای لوکال:
NODE_ENV=development
COOKIE_SECURE=false
TRUST_PROXY=0
SESSION_SECRET=یک-عبارت-طولانی-تصادفی

نکته: تست runtime کامل EJS در محیط ساخت انجام نشد چون نصب npm در محیط ساخت timeout شد؛ بررسی Syntax فایل‌های JS موفق بود.
